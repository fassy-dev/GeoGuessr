# GeoGuessr 🌍

## 🚀 Особенности (Features)
* **Python Backend** — легкий и производительный сервер на базе Python.
* **Интерактивный геймплей** — угадывайте локации и зарабатывайте очки на основе точности.
* **Простая интеграция** — легко развернуть локально или на сервере.

## 💻 Установка и запуск (Installation & Setup)

Выполните следующие шаги для локального запуска проекта.

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd GeoGuessr
```

### 2. Настройка виртуального окружения (Рекомендуется)
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate
```

### 3. Установка зависимостей
*(Если у вас появится файл requirements.txt)*
```bash
pip install -r requirements.txt
```

### 4. Запуск сервера
```bash
python server.py
```
